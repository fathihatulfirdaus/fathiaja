# fathiaja
nama:fathihatul firdaus
nim:C2583207041
kelas:PTI3A
Program yang kami buat adalah Sistem Monitoring Stok dan Penjualan Kantin Kampus menggunakan bahasa pemrograman C. Tujuan dari program ini adalah untuk mempermudah pengelola kantin dalam mengatur data makanan dan minuman, memantau stok barang, serta mencatat hasil penjualan.
Di dalam program ini terdapat 9 fitur utama, mulai dari melihat daftar produk, menambahkan produk, mengubah data produk, melakukan transaksi penjualan, menambah stok, mencari produk, mengurutkan produk, membuat laporan penjualan, hingga mengecek stok yang mulai menipis.
